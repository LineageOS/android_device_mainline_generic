# x86 platform

## Build live ISO image with linux-firmware included

Firstly, get the linux-firmware files in a directory, which can come from these ways:
- Clone linux-firmware repository from [upstream](https://gitlab.com/kernel-firmware/linux-firmware),
and run its `copy-firmware.sh` script with output directory specified. Note that using the files from
the repository directly will result in missing symbolic links.
- Use the files in `/lib/firmware` from a Linux OS installation on the target device.

Then, pack the directory containing linux-firmware files into a image named `linux-firmware.img`:
```
mkfs.erofs -zlzma linux-firmware.img <path to the directory containing linux-firmware files>
```

Finally, build the live ISO image with the following environment variable set:
```
TARGET_LINUX_FIRMWARE_IMAGE=<absolute path to the linux-firmware.img which we have made>
```
